# 팝업 문서 시스템

## 목적

관리자가 HTML 또는 일반 편집기로 안내 문서를 작성하고, 지정한 화면과 게시 기간에 맞춰 그룹웨어에 자동 노출한다. 공개 사이트용 데이터 계약은 준비되어 있지만 공개 사이트 연결은 별도 Phase 승인 전까지 활성화하지 않는다.

## 노출 위치

- 그룹웨어 전체(로그인 후 첫 화면), 대시보드, 게시판, 전자결재, 관리자
- 공개 사이트 전체, 메인, 개인정보처리방침은 데이터 계약만 준비됨(현재 관리자 UI와 공개 사이트 노출 비활성)

`groupware_all`과 `public_all`은 각 영역의 모든 세부 위치에 적용한다. 사용자가 닫은 문서는 같은 브라우저 탭 세션에서는 다시 열지 않는다.

## 작성과 표시

- 일반 편집기: 제목·목록·굵게·기울임·인용 서식
- HTML 편집기: 허용 태그와 제한된 인라인 스타일
- 게시 시작·종료 시각, 활성 여부, 정렬 순서, 보관 상태
- 여러 팝업이 동시에 게시 중이면 정렬 순서대로 이어서 표시
- HTML은 저장 전과 출력 직전에 정화하며 스크립트, 이벤트 속성, 폼, iframe과 위험 URL을 제거한다.

## 권한과 데이터

- 테이블: `popup_documents`
- 공개·그룹웨어 조회: `get_active_popup_documents(text)`
- 관리자 목록: `get_popup_admin_catalog()`
- 관리자 저장: `manage_popup_document(jsonb)`
- 생성·수정은 승인된 관리자만 가능하며 감사 로그에는 본문을 제외한 설정 변경만 기록한다.

마이그레이션 `202608050002_popup_documents.sql`은 그룹웨어 로그인 후 표시되는 `재경닷컴 그룹웨어 이용 안내` 예시 문서를 함께 생성한다.
