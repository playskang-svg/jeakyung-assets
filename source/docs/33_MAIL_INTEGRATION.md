# IWINV Terra Mail 연동

## 범위와 원칙

- 대상 서비스는 IWINV Terra Mail이다.
- 사용자 접속 주소는 `https://mail.jeakyung.com`이다.
- 메일은 인증·회원·권한 시스템이 완성된 뒤 별도 모듈로 연결한다.
- G0–G1에서는 iframe, API, IMAP, SMTP와 실제 계정을 연결하지 않는다.
- 평문 비밀번호를 저장하거나 그룹웨어 로그인 비밀번호를 메일 인증에 재사용하지 않는다.

## 연동 우선순위

1. 공식 SSO와 허용된 iframe
2. 공식 계정 API 또는 제한된 인증 토큰
3. 서버 측 IMAP·SMTP 기반 자체 메일 UI

앞선 방식이 공식 지원되지 않거나 보안 검토를 통과하지 못할 때만 다음 방식을 검토한다.

## 사전 확인 사항

- 공식 SSO 프로토콜, iframe 허용 도메인과 CSP
- 계정 API, 토큰 범위, 만료·회수와 감사 기능
- 계정 생성·잠금·비밀번호 변경·퇴사 처리 API 지원 여부
- IMAP·SMTP 호스트, 포트, TLS, OAuth 또는 앱 비밀번호 지원 여부
- 라이선스, 사용자 수, 저장 용량, 보존·백업 정책
- 장애 대응, 개인정보 처리 위탁과 로그 보유 기준

모든 항목은 현재 `[미정]`이며 공급자 공식 문서와 계약 담당자 확인이 필요하다.

## 계정 자동화

- 생성, 비밀번호 변경, 잠금과 퇴사 처리는 공식 API가 지원되고 보안 검토가 완료된 경우에만 자동화한다.
- 관리자 브라우저에서 메일 관리자 비밀번호나 고권한 토큰을 다루지 않는다.
- 자동화는 서버 함수에서 최소 권한 토큰을 사용하고 모든 작업을 감사한다.

## 자체 UI를 선택할 경우

- 메일 자격 증명을 브라우저 저장소에 보관하지 않는다.
- 브라우저가 IMAP·SMTP 서버에 직접 연결하지 않는다.
- 서버 측 암호화, 키 관리, 세션 분리와 전송 구간 TLS가 필요하다.
- 첨부파일 검사, HTML 메일 정화, 피싱·외부 이미지 정책을 마련한다.
- 구현·운영 복잡도 때문에 공식 SSO/API보다 우선하지 않는다.

## 현재 UI

`/groupware/mail`에는 예정 기능과 연동 대기 상태만 표시한다. G2에서는 실제 메일 연결을 하지 않으며 공개 사이트의 기존 `https://jeakyung.quv.kr` 링크는 운영 전환 승인 전까지 유지한다.
