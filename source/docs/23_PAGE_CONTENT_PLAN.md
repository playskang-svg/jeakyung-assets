# 페이지 콘텐츠 계획

## 인증 페이지

### 로그인

- 재경닷컴 그룹웨어 브랜드와 임직원 전용 안내
- 이메일, 비밀번호, 표시·숨김, 로그인 상태 유지
- 로그인 버튼, 비밀번호 재설정, 가입 신청
- 승인 전 계정 안내와 접근 가능한 오류 영역
- G2에서는 Supabase Auth와 회원 상태를 연결하고 설정 누락 시 연결 필요 상태를 안내한다.

### 가입 신청

- 이름, 회사 이메일, 연락처, 비밀번호, 비밀번호 확인
- 부서, 직급, 직책을 Supabase의 활성 조직 기준에서 선택
- 역할은 신청자가 선택하지 않으며 관리자가 승인할 때 확정
- 제출 시 실제 회원을 생성하지 않고 연동 전 상태를 안내한다.

### 승인 대기

- 신청 접수와 관리자 승인 후 사용 가능 안내
- 이메일 표시 영역, 로그인으로 돌아가기, 경영지원부 문의 안내
- URL이나 저장소에 개인정보를 영구 보관하지 않는다.

### 비밀번호 재설정

- 이메일, 요청 버튼, 로그인으로 돌아가기
- 성공·오류 메시지 영역
- G2에서는 Supabase 비밀번호 복구 메일과 `/groupware/reset-password/update` 새 비밀번호 화면을 사용한다.

## 내부 페이지 골격

| 페이지 | 향후 구성 요소 |
| --- | --- |
| 대시보드 | 내 업무, 결재 대기, 최근 게시글, 일정, 공지 |
| 이메일 | 받은편지함, 보낸편지함, 임시보관, 검색, 편지쓰기 |
| 조직도 | 부서 트리, 직원 검색, 직원 목록, 직원 상세 |
| 게시판 | 즐겨찾기, 최근 게시판, 권한별 게시판 그룹, 공지 |
| 게시판 상세 | 카테고리, 글 목록, 검색·필터, 페이지 이동 |
| 게시글 상세 | 본문, 작성자 표시, 첨부, 댓글, 권한 작업 |
| 글쓰기 | 제목, 카테고리, 본문, 첨부, 공지·익명 옵션 |
| 전자결재 | 결재 대기, 진행, 완료, 반려, 양식 |
| 일정 | 개인·부서·전사 일정, 달력, 일정 상세 |
| 파일 | 개인·부서·공용 파일, 검색, 용량, 권한 |
| 관리자 | 회원 승인, 조직, 역할·권한, 게시판, 시스템, 감사 로그 |

현재 내부 페이지에는 실제 데이터나 CRUD 대신 위 영역을 식별할 수 있는 설명 카드만 표시한다.

## 대시보드 위젯 후속 기준

- 노출 대상: 전체, 역할, 부서, 직급·직책, 특정 사용자.
- 설정: 제목, 순서, 크기, 활성 상태, 필수 고정 여부, 사용자 숨김 허용 여부, 연결 경로.
- 필수 고정 위젯은 사용자가 숨길 수 없으며 권한 없는 연결 경로를 제공하지 않는다.
- G2에서는 요구사항과 향후 데이터 확장 지점만 정의하며 위젯 빌더 UI와 저장 기능은 구현하지 않는다.
