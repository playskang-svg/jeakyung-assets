# References

## 1. 문서 목적

이 문서는 웹사이트 제작에 제공된 참고 자료가 어느 페이지와 Section에 연결되는지, 무엇을 참고하거나 실제로 사용하는지, 그리고 적용 범위와 권리 조건을 기록한다.

- 전체 웹사이트 요구사항은 [`../WEBSITE_SPEC.md`](../WEBSITE_SPEC.md)를 기준으로 한다.
- 실제 파일 정보와 물리적 상태는 [`11_ASSET_MANIFEST.md`](11_ASSET_MANIFEST.md)를 기준으로 한다.
- 상세 자산 정보를 이 문서에 반복하지 않고 Asset ID로 연결한다.
- 사용자 승인 없이 참고 자료를 실제 코드에 추가 적용하거나 변형하지 않는다.

## 6. 적용 원칙

- 참고 자료의 디자인을 그대로 복제하지 않는다.
- 참고할 요소를 구도, 색감, 배치 등으로 구분해 기록한다.
- `Reference Only` 자료를 실제 사이트 파일로 사용하지 않는다.
- 실제 사용 자산은 Asset ID와 권리 상태를 반드시 연결한다.
- 모바일에서 임의로 자료를 제거하거나 다른 장면으로 바꾸지 않는다.
- 기기별 크롭, 축약 또는 대체가 필요하면 사용자 승인을 받는다.
- 참고 자료와 실제 구현이 달라진 경우 변경 이유와 승인 상태를 갱신한다.
