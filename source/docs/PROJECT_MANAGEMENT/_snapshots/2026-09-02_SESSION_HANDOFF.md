## 이번 세션에서 끝낸 것

### 1. 지입업무 탭 페이지 (`/pages/consignment`)

```
지입업무 │ [차량관리][운송사관리][계약서류][정산][민원·문의]   ← 고정 메뉴줄
─────────────────────────────────────────────────────
[버튼][버튼]          ← 그 탭의 버튼 박스
게시판 (사업부 분류 5 + 목록)   ← 그 탭의 게시판
```

**원래 왜 안 됐나**: 버튼 박스가 페이지에 하나뿐이었고, 페이지에 박스가 있으면
탭을 통째로 감췄다 — 버튼과 탭 중 **하나만** 고를 수 있었다. 박스를 페이지가
아니라 **항목(탭)에** 매달아 두 층이 함께 서게 했다.

메뉴줄은 상단바 바로 밑에 붙어 스크롤해도 남는다(`position: sticky; top: 56px`).

게시판 5개(`consign-vehicle` / `-carrier` / `-contract` / `-settle` / `-inquiry`)는
각각 사업부 분류 5개를 달았고 **대시보드 숨김** 상태다.

**⚠️ 탭 5개의 버튼 박스는 아직 비어 있다.** 관리자 → 버튼 박스에서 채우면 된다.

### 2. 게시판 전체 검색

상단바 검색창 → `/search?q=…`. 볼 수 있는 게시판 전체에서 제목·말머리·본문을
훑는다.

본문이 두 곳에 있다(옛 글 `content`, 지금 글 `content_document`). 후자는
**텍스트 노드만** 뽑아 비교한다 — jsonb 를 통째로 문자열로 바꾸면 속성 이름이나
이미지 주소에까지 걸린다. 검색어의 `%` 와 `_` 는 이스케이프한다.

검색을 꺼 둔 게시판은 뺀다. **대시보드에서 감춘 게시판은 포함한다** — 감춘 것은
목록에서일 뿐 못 읽는 글이 아니고, 찾을 수 없으면 그 글은 영영 묻힌다.

### 3. 상단바

- 검색창 (좁은 화면에서는 돋보기로 접힘, 누르면 펼쳐짐)
- 날짜·시계·일정 버튼 (좁은 화면에서는 일정 버튼만)
- 인트라넷 홈 아이콘 — 옆의 '홈페이지'는 회사 웹사이트로 나가므로 따로 뒀다
- '현재 위치 / 화면이름' 덩어리 제거 — 바로 아래 경로 줄이 더 자세히 보여 준다

### 4. 바깥 주소를 화면 안에서 연다

`/view/<key>` → `EmbeddedSite` 로 액자에 담는다. 사내메일·적격수급평가·대표님·
결제 링크 발송·지입업무(`jeakyung.quv.kr/41`).

**주소를 경로에 싣지 않았다.** 그러면 누구나 주소만 바꿔 임의의 사이트를 우리
화면에 띄울 수 있다. `navigation.js` 에 적어 둔 항목의 `key` 로만 찾는다.

**미확인**: 상대 사이트가 `X-Frame-Options` 로 액자를 거부하는지는 확인하지
못했다(개발 환경에서 바깥 요청이 전부 403). 거부하면 4초 뒤 "새 탭에서 열기"
안내가 뜬다. 결제 계열(payapp)은 대개 막아 둔다.

### 5. 링크로 만든 버튼의 글씨가 안 보이던 것 — 뿌리에서

세 번 같은 증상이 났다(글쓰기 → 수정 → 관리자 모드). 원인은 매번 같았다:

```css
body.groupware-root a { color: inherit }   /* (0,1,2) */
.gw-admin-mode-button  { color: #fff }     /* (0,1,0) — 진다 */
```

리셋 한 줄이 **클래스 하나로 색을 정한 버튼을 전부** 이긴다. 버튼마다 예외를
다는 대신 `:where(body.groupware-root) a` 로 우선순위를 0 으로 낮췄다.
앞으로 새 링크 버튼도 같은 함정에 빠지지 않는다.

### 6. 그 밖에

- 첨부파일 이름이 깨져 내려오던 것 → 파일을 받아 온 뒤 이름을 브라우저에
  문자열로 직접 준다(`downloadAttachment`). 저장소가 만드는
  `Content-Disposition` 헤더는 ASCII 만 안전하게 담는다.
- 돌아갈 버튼 세 벌 → 경로 줄 하나로 (화살표 6곳, 전자결재 이동 줄 제거)
- 게시판 설정 20개 → 4개 (댓글·파일 첨부·본문 이미지·익명 작성) + **대시보드 숨김**
- 팝업 삭제, 보관한 게시판 목록에서 감춤(`보관함 보기`로 복구)
- 좋아요·반응 제거, 공지·최신글 3줄, 글꼴 6종, 게시판 상단 바로가기 버튼 제거
- '이동하기'를 게시판 판에서 떼어 별도 박스로
- 페이지 제목 18px (업무 페이지 메뉴줄 제목과 같게)

## 아직 안 한 것 (다음 작업)

### A. 이동하기 버튼 박스를 관리자에서 관리 — **가장 큰 남은 일**

사용자 요구사항 원문 요약:

1. 관리자 메뉴에서 **따로 생성**하고 버튼을 **추가·편집·삭제**
2. 텍스트를 **고르는 게 아니라 입력**, 연결 주소도 **입력** (심플하게)
3. 링크는 **새 창이 아니라 헤더 밑에서** 열린다
4. 사내메일뿐 아니라 **전자결재도 색이 들어가게** — 버튼별 색 지정
5. **버튼 크기 조절** 기능

지금은 `source/src/groupware/config/navigation.js` 의 `quickLinks()` 에
**코드로 박혀** 있다. DB 로 옮겨야 한다.

제안 스키마 (미적용):

```sql
create table public.quick_links (
  id uuid primary key default gen_random_uuid(),
  label text not null,
  url text not null,        -- 바깥 주소(https://…) 또는 내부 경로(/approval)
  accent boolean not null default false,   -- 색 채운 버튼
  sort_order integer not null default 100,
  is_active boolean not null default true,
  ...
);
```

버튼 크기는 행마다가 아니라 **줄 전체에 하나**면 충분하다(설정 한 값).

`/view/:viewKey` 는 지금 `navigation.js` 의 key 로만 찾는다. DB 행도 찾도록
넓혀야 하는데, **경로에 주소를 직접 싣지 말 것** (위 4번 항목의 이유와 같다).

## 일하는 방식 (이 저장소에서 배운 것)

**절대 하지 말 것**: 이미 배포된 화면을 건드리는 것. 사용자가 여러 번 못박았다 —
"지금 여기서 업데이트 한건 바꾸면 안돼. 그룹웨어나 없는 부분만 가져와서 작업해야지."

**DB 함수 고칠 때**: 옛 마이그레이션 파일에서 다시 쓰지 말 것. 살아 있는 정의를
`pg_get_functiondef()` 로 읽어 필요한 substring 하나만 `replace()` 하고
(개수가 정확히 1인지 확인) `execute` 한다. 통째로 다시 쓰면 그 사이 변경이
조용히 되돌아간다.

**`manage_board` / `manage_link_page` 는 통째로 교체한다** — 넘기지 않은
규칙·담당자·분류를 지운다. 더하기만 할 때는 직접 insert 가 안전하다.

**CSS 우선순위 함정**: `body.groupware-root a` 는 (0,1,2) 다. 그리고 **media
블록은 기본 규칙보다 뒤에 와야 이긴다** — 파일 앞쪽 640px 블록에 넣으면
나중에 나오는 기본 규칙에 밀려 아무 일도 일어나지 않는다. 이걸로 한 번 헤맸다.

**눈으로 믿지 말 것**: 화면은 PNG 로 렌더해서 픽셀을 읽고, 색은
`getComputedStyle` 로 확인한다. 좁은 화면은 `scrollWidth == innerWidth` 로
넘침을 잰다 — 상단바가 넘치면 문서 전체가 오른쪽으로 밀린다(실제로 두 번 났다).

**Supabase 트랜잭션**: `set local role authenticated` 상태에서 권한 없는 테이블을
select 하면 DO 블록 전체가 롤백된다. 결과는 `set_config('my.out', …, false)` 로
빼서 role 을 되돌린 뒤 읽는다.

**한글 조사**: 컴(받침) → 은/이, 류(받침 없음) → 는/가. 이름 바꿀 때 조사도 봐야 한다.
