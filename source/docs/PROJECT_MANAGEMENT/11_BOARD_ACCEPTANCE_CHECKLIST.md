# 게시판 운영 인수 검수 체크리스트

[문서 목록](./00_INDEX.md) · [현재 상태](./02_CURRENT_STATUS.md) · [게시판 기준](../29_BOARD_SYSTEM.md)

## 목적

최고관리자가 만든 게시판이 사용자별 읽기·쓰기·댓글 권한에 따라 정확히 노출되고, 직접 URL과 첨부파일에서도 같은 권한이 적용되는지 확인한다.

## 검수 전 조건

- 전체 마이그레이션과 `202608050001_board_types_and_permission_delivery.sql` 적용
- 활성 역할이 `super_admin`인 최고관리자 1명
- 활성 역할이 `employee`인 일반 사용자 2명
- 서로 다른 부서에 속한 사용자 각 1명
- 테스트 데이터는 운영 데이터와 구분하고 검수 후 보관 또는 정리

## A. 게시판 생성

- [ ] `/groupware/admin/boards` 직접 접근 성공
- [ ] 통합게시판 생성 성공
- [ ] 갤러리 생성 성공
- [ ] 댓글형 게시판 생성 성공
- [ ] 게시판명·slug·그룹·설명·카테고리 저장 확인
- [ ] 카테고리명 변경 후 기존 게시글의 카테고리 연결 유지
- [ ] 제거한 카테고리는 삭제하지 않고 비활성화
- [ ] 최고관리자의 게시판 그룹 수정·보관 성공
- [ ] 읽기 허용이 하나도 없으면 저장 차단
- [ ] 중복 slug 저장 차단
- [ ] 생성·수정 감사 로그 기록

## B. 읽기 권한과 사용자 노출

- [ ] 전체 사용자 읽기 허용 시 승인된 직원 Sidebar에 노출
- [ ] 역할 읽기 허용 시 해당 활성 역할 사용자에게만 노출
- [ ] 부서 읽기 허용 시 해당 부서 사용자에게만 노출
- [ ] 특정 사용자 읽기 허용 시 지정 사용자에게만 노출
- [ ] `sidebar_view`와 `list_read` 중 하나라도 없으면 목록에서 숨김
- [ ] 읽기 권한 없는 사용자의 게시판 직접 URL 차단
- [ ] 상세 읽기 권한 없는 사용자의 게시글 직접 URL 차단

## C. 허용과 거부 우선순위

- [ ] 전체 사용자 읽기 허용 + 특정 사용자 읽기 거부 시 해당 사용자만 차단
- [ ] 역할 쓰기 허용 + 특정 사용자 쓰기 거부 시 해당 사용자만 글쓰기 차단
- [ ] 부서 댓글 허용 + 특정 사용자 댓글 거부 시 해당 사용자만 댓글 차단
- [ ] 활성 역할 변경 후 역할 권한이 즉시 다시 계산됨
- [ ] `localStorage` 변경으로 권한 상승 불가

## D. 쓰기 권한

- [ ] 쓰기 허용 사용자에게 글쓰기 버튼 노출
- [ ] 쓰기 차단 사용자에게 글쓰기 버튼 미노출
- [ ] 쓰기 차단 사용자의 `/write` 직접 접근과 draft 생성 차단
- [ ] 본인 글 수정·삭제 권한 확인
- [ ] 타인 글 수정·삭제는 고급 권한이 없으면 차단
- [ ] 일반 첨부와 본문 이미지 업로드 권한 재검증
- [ ] 글 작성 중 일반 첨부파일 추가·삭제 성공

## E. 댓글 권한

- [ ] 댓글 허용 사용자에게 댓글 입력 폼 노출
- [ ] 댓글 차단 사용자에게 댓글 입력 폼 미노출
- [ ] 댓글 생성 RPC 직접 호출도 차단
- [ ] 본인 댓글 수정·삭제 성공
- [ ] 타인 댓글 수정·삭제는 고급 권한이 없으면 차단
- [ ] 댓글형 게시판이 최근 댓글 활동순으로 정렬됨

## F. 유형별 표시

- [ ] 통합게시판이 기본 목록형으로 표시
- [ ] 갤러리가 대표 이미지 카드형으로 표시
- [ ] 갤러리 대표 이미지가 없는 글의 빈 상태 표시
- [ ] 댓글형 게시판에 댓글 수·본문 요약·최근 활동일 표시
- [ ] 검색 비활성 게시판에서 검색 입력을 숨기고 서버도 검색어를 무시
- [ ] 최신·오래된 글·인기 글 정렬과 전체 페이지 수 확인
- [ ] 작성자 부서·직급·직책 표시 설정 확인
