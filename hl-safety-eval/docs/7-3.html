안전보건교육 교안

유한회사 재경물류 | 원청사 HL홀딩스(주) | 현장 동탄냉장 물류센터

냉장·냉동 물류센터 특화 교안 5종

※ 각 교안은 20~30분 분량이며, 자체 정기교육 및 채용 시 교육에 사용한다. 교육 후 확인문항으로 이해도를 점검하고 결과를 교육일지에 기록한다.

교안 1. 지게차 안전 — 충돌·전도 예방

학습 목표 · 지게차 사고 3대 유형과 원인을 설명할 수 있다 · 시업 전 일상점검을 스스로 수행할 수 있다 · 보행자로서 지켜야 할 수칙을 안다

■ 지게차 사고 3대 유형

  • 보행자 충돌 — 사각지대, 후진 시 미확인이 주원인. 우리 현장 위험성평가 RA-04, RA-06 해당.
  • 전도(넘어짐) — 과적, 급선회, 포크 상승 상태 주행. RA-05 해당.
  • 협착 — 마스트·차체와 구조물 사이 끼임.

■ 시업 전 점검 (조별 매일)

  • 브레이크(주·주차), 조향장치 유격, 경음기
  • 후진경보음·경광등, 전조등·후미등, 후사경
  • 포크 균열·변형·고정핀, 마스트·체인, 유압 누유
  • 타이어 마모·공기압, 안전벨트, 배터리 단자
  • 이상 발견 시 즉시 사용중지 후 관리감독자(김수호·박천희)에게 보고

■ 운행 수칙

  • 유자격자만 운전 (지게차운전기능사 또는 3톤 미만 교육이수)
  • 안전벨트 착용, 제한속도 10km/h 이하
  • 주행 시 포크는 지면에서 20~30cm 하강 상태 유지
  • 후진 시 반드시 후방 확인 + 경음기 사용
  • 교차부·출입구 일단정지 후 진행
  • 포크에 사람 탑승 절대 금지
  • 주차 시 포크 하강, 시동 정지, 키 분리

■ 보행자 수칙

  • 형광 안전조끼 착용 필수
  • 보행자 전용통로로만 이동, 지게차 구역 횡단 금지
  • 운전자와 눈맞춤 후 통과
  • 지게차 반경 3m 이내 접근 금지, 적재물 하부 통행 금지

교안 2. 핸드파렛트(수동 운반기) 안전 취급

학습 목표 · 핸들 조작 시 발등 협착 위험을 안다 · 적재중량 상한과 2인 운반 기준을 안다 · 경사·곡선 구간 취급법을 안다

■ 주요 위험 (위험성평가 RA-09, RA-10)

  • 발등 협착 — 핸들을 당기거나 방향 전환 중 바퀴가 발등을 타고 넘음. 물류현장에서 가장 흔한 부상.
  • 손 끼임 — 핸들 하강 레버 조작 중 구조물과 손 사이 끼임.
  • 제동 불가 충돌 — 과중량 적재 시 관성으로 멈추지 못해 사람·설비와 충돌.
  • 허리 부담 — 무리한 힘으로 밀거나 당길 때 근골격계 손상.

■ 안전 취급 수칙

  • 발 위치 — 바퀴 진행선상에 발을 두지 않는다. 몸은 진행방향 옆쪽에 둔다.
  • 안전화 착용 필수 — 발등 보호가 되는 제품을 착용한다.
  • 적재중량 상한 준수 — 차체에 표시된 상한을 넘기지 않는다. 초과 시 2회로 나눈다.
  • 경사·내리막에서는 밀지 말고 당긴다 — 밀면 관성으로 제어 불가.
  • 곡선구간 서행 — 시야를 확보하고 회전 반경을 크게 잡는다.
  • 2인 1조 기준 — 중량이 크거나 경사가 있는 구간은 2인이 취급한다.
  • 일상점검 — 바퀴 파손, 유압 누유, 핸들 유격, 포크 변형을 시업 전 확인한다.
  • 주차 — 통로를 막지 않고 포크를 완전히 내려 둔다.

교안 3. 냉장·냉동구역 저온작업 안전

학습 목표 · 저온 노출 건강장해를 설명할 수 있다 · 휴식주기와 방한보호구 착용법을 안다 · 냉동창고 갇힘 대응요령을 안다

■ 저온 건강장해 (RA-13)

  • 동상 — 손끝·발끝·귀·코. 감각 저하 후 창백·경직.
  • 저체온증 — 떨림, 판단력 저하.
  • 저온에 의한 근육 경직 → 낙상·끼임 2차 재해 유발.

■ 작업 관리 기준

  • 냉동구역(-18℃ 이하) 연속작업 60분 이내, 작업 후 20분 이상 회복 휴식
  • TBM에서 입실·퇴실 시각을 사전 배정한다
  • 2인 1조 작업 원칙 — 단독작업 금지 (RA-14)
  • 작업 전 건강상태 확인 (음주·수면 부족 시 배제)
  • 따뜻한 음료 제공, 젖은 옷 즉시 교체

■ 방한보호구

  • 방한복(상하) -25℃ 대응 / 방한장갑 미끄럼방지 / 방한모·넥워머
  • 내한·미끄럼방지 안전화
  • 젖은 상태로 착용 금지, 사용 후 건조 보관

■ 냉동창고 갇힘 대응 (RA-14)

  • 출입 전 비상탈출 손잡이·비상벨 위치 확인
  • 출입 시 관리감독자 또는 상대 조에 통보
  • 갇힘 발생 시 비상벨 작동 → 내부 개방장치 사용
  • 구석·바닥 접촉을 피하고 움직여 체온 유지

■ 결빙 미끄러짐 예방 (RA-15)

  • 조별 시업 전 바닥 결빙·결로 확인 및 제빙
  • 미끄럼방지 매트 상태 확인
  • 보폭을 좁게, 손에 물건을 가득 들고 이동 금지
  • 입출구 온도차 구간 특히 주의

교안 4. 도크·랙·중량물 안전

학습 목표 · 도크 작업 추락·협착 위험을 안다 · 고임목 등 차량 고정 절차를 수행할 수 있다 · 랙 적재 기준과 손상 랙 대응을 안다

■ 도크 작업 (RA-01, RA-02, RA-19)

  • 차량 접안 → 시동 정지 → 고임목 설치 → 운전자 하차 확인 후 작업 개시
  • 차량키 보관제 운영 (작업 완료까지 관리자 보관)
  • 도크 레벨러 정상 안착 확인 후 진입
  • 미사용 도크는 차단봉·안전바 설치
  • 작업 중 차량 이동금지 표지 부착

■ 랙 적재 (RA-11, RA-12)

  • 적재하중 표시판 확인, 초과 적재 금지
  • 파렛트 2단 초과 적재 금지
  • 무거운 화물은 하단, 가벼운 화물은 상단
  • 고소 적재물 취급 시 하부 통행 통제
  • 랙 기둥 휨·손상 발견 시 즉시 하역 후 사용중지 표시 → 원청(HL홀딩스)에 통보. 임의 보수·용접 금지 (랙은 원청 소유 설비)

■ 중량물 취급 (RA-18)

  • 1인 취급 한도 : 남성 25kg, 여성 15kg
  • 초과 시 2인 이상 또는 핸드파렛트 사용
  • 물건 가까이 다가서기 → 무릎을 굽히고 허리는 곧게 → 다리 힘으로 들기
  • 몸통을 비틀지 말고 발을 움직여 방향 전환
  • TBM 시 스트레칭 3~5분 실시

교안 5. 화재예방·비상대응 및 아차사고 신고

학습 목표 · 물류센터 화재 위험요인을 안다 · 소화기를 사용할 수 있다 · 비상상황별 대응절차와 신고제도를 안다

■ 화재 위험 (RA-08, RA-23)

  • 지게차 배터리 충전 중 수소가스 축적 — 충전구역 환기 유지, 인화물 제거
  • 전기설비 과부하·누전, 문어발 배선
  • 대량 적재물로 인한 급속 연소·유독가스
  • 소화기·소화전 주변 1m 이내 적치 금지, 비상구·피난통로 적치 금지
  • 오후조 마감 시 충전상태·인화물·전원 차단 확인

■ 소화기 사용법 (P.A.S.S)

  • Pull — 안전핀을 뽑는다 / Aim — 노즐을 불의 밑부분에 겨눈다
  • Squeeze — 손잡이를 움켜쥔다 / Sweep — 좌우로 쓸듯이 분사한다
  • 바람을 등지고, 대피로를 등 뒤에 두고 사용

■ 비상상황별 대응

  • 화재 : 큰소리 전파 → 119 신고 → 초기소화(가능 시) → 대피 → 집결지 인원 확인 → 원청 통보
  • 냉매 누출 : 즉시 대피(풍상측) → 저지대 접근 금지 → 원청 설비담당 즉시 통보 → 구역 출입통제 (기계실 임의 진입 금지)
  • 지게차 사고 : 작업중지 → 응급조치·119 → 현장 보존(사진) → 원청 통보 → 재해조사
  • 정전 : 작업중지, 지게차 정차 후 하차, 냉동구역 인원 즉시 확인·대피

■ 대피 요령

  • 낮은 자세, 젖은 수건으로 코·입 보호, 엘리베이터 사용 금지
  • 집결지 집합 후 조별 인원 점검 (오전 김수호 / 오후 박천희)

■ 아차사고 신고제도

  • 아차사고란 재해로 이어질 수 있었으나 피해가 없었던 사건이다.
  • 발견 즉시 관리감독자에게 보고 → 아차사고 대장 기록 → 원인 분석 → 개선 → 결과 공유
  • 신고자에게 어떠한 불이익도 없으며, 우수 신고자는 분기별 포상한다.
  • 작업중지권 : 급박한 위험이 있다고 판단되면 누구든 작업을 중지할 수 있다. 중지 후 관리감독자에게 보고하고, 위험 해소 확인 후 관리자가 재개를 결정한다.
